## Informational corpus-scoring limit

The plan does not define an ASR normalized-text or cue-timing acceptance tolerance. The retained corpus-output diagnostic is therefore informational, not a pending Phase 3 acceptance gate. If a future acceptance decision needs such a score, agree and record the tolerance first; do not retroactively treat the current overlap or word-edit measurement as pass/fail evidence.

Until every applicable row in the release matrix is supported by retained evidence for both architectures, this repository must not be described as release-ready or overall-UAT green.
